## Sympy 怎么求 Q

可以，最直接就是用 **QR 分解（QR decomposition）**：

```python
from sympy import Matrix

A = Matrix([
    [1, 1],
    [1, 2],
    [1, 3],
])

Q, R = A.QRdecomposition()

Q
```

这里返回的 `Q` 就是你要的**列标准正交矩阵**。

也就是：

\[
A=QR
\]

其中

\[
Q^TQ=I.
\]

如果你只是想做 **Gram–Schmidt 正交化**，也可以直接：

```python
from sympy import Matrix, GramSchmidt

a1 = Matrix([1, 1, 1])
a2 = Matrix([1, 2, 3])

qs = GramSchmidt([a1, a2], True)

qs
```

第二个参数 `True` 表示**标准化**，所以返回的就是

\[
q_1,q_2,\dots
\]

这些标准正交向量。

如果你想把它们拼成 \(Q\)：

```python
Q = Matrix.hstack(*qs)
Q
```

所以可以这样记：

- `A.QRdecomposition()`：直接得到 \(Q,R\)
- `GramSchmidt([...], True)`：直接得到 \(q_1,q_2,\dots\)

如果你现在是在学 Strang 这部分，我更推荐先用 `GramSchmidt`，因为它和你刚才“连续剥掉投影分量”的过程是一一对应的。
