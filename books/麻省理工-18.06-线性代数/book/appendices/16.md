## sympy 能算$e_i$吗？

可以。

SymPy 不一定有一个专门叫“算每个 \(e_i\)”的函数，但最直接就是先算最小二乘解，再算残差向量：

```python
from sympy import Matrix

A = Matrix([
    [1, 1],
    [1, 2],
    [1, 3],
])

b = Matrix([1, 2, 2])

x_hat = A.solve_least_squares(b)

e = b - A * x_hat

print(x_hat)
print(e)
```

会得到：

```python
Matrix([[2 / 3], [1 / 2]])

Matrix([[-1 / 6], [1 / 3], [-1 / 6]])
```

所以：

\[
e=
\begin{bmatrix}
e_1\\
e_2\\
e_3
\end{bmatrix}
=
\begin{bmatrix}
-\frac16\\
\frac13\\
-\frac16
\end{bmatrix}
\]

如果你想单独取某个 \(e_i\)：

```python
e[0]  # e1
e[1]  # e2
e[2]  # e3
```

注意 Python 下标从 0 开始。

还可以验证最小二乘条件：

```python
A.T * e
```

结果应为：

```python
Matrix([[0], [0]])
```

也就是：

\[
\boxed{A^Te=0}
\]

说明残差向量 \(e\) 与 \(A\) 的列空间正交。

如果还想算残差平方和：

```python
sse = (e.T * e)[0]
```

也就是：

\[
\boxed{\sum e_i^2=e^Te}
\]

所以在 SymPy 里，最实用的流程就是：

```python
x_hat = A.solve_least_squares(b)
e = b - A * x_hat
```

这两行基本就够了。
