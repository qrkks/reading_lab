## 向量$a^Ta aa^t$是有关系的，矩阵$A^TA AA^t$是没关系的？

不是“矩阵时就没关系”，恰恰相反：**\(A^TA\) 和 \(AA^T\) 关系非常深。**

而且你刚才向量的情况，其实就是矩阵情况的一个特例。

如果把列向量 \(a\) 看成一个 \(n\times1\) 的矩阵 \(A\)，那么

\[
A^TA=a^Ta
\]

是一个 \(1\times1\) 标量，而

\[
AA^T=aa^T
\]

是一个 \(n\times n\) 矩阵。

所以你刚才研究的 \(a^Ta\) 和 \(aa^T\)，本质上就是在研究 \(A^TA\) 和 \(AA^T\)。

对于一般矩阵

\[
A\in\mathbb R^{m\times n},
\]

有

\[
A^TA\in\mathbb R^{n\times n},
\qquad
AA^T\in\mathbb R^{m\times m}.
\]

它们通常**不是同一个矩阵**，甚至维度都可能不同，但有几个非常重要的共同点：

\[
\boxed{\operatorname{rank}(A^TA)
=\operatorname{rank}(AA^T)
=\operatorname{rank}(A)}
\]

并且

\[
\boxed{\operatorname{tr}(A^TA)
=
\operatorname{tr}(AA^T)
=
\sum_{ij}a_{ij}^2
=
\|A\|_F^2}
\]

这里的 \(\|A\|_F\) 是 **Frobenius norm（弗罗贝尼乌斯范数）**。

更重要的是：

\[
\boxed{A^TA \text{ 和 } AA^T
\text{ 有完全相同的非零特征值}}
\]

这些非零特征值就是

\[
\sigma_1^2,\sigma_2^2,\dots
\]

也就是 \(A\) 的 **singular values（奇异值）** 的平方。

这正是你马上学 SVD 时最核心的关系：

\[
A^TA v_i=\sigma_i^2v_i,
\]

\[
AA^T u_i=\sigma_i^2u_i.
\]

所以可以这样理解：

\[
\boxed{
A^TA\text{ 研究输入空间/行空间一侧},
\quad
AA^T\text{ 研究输出空间/列空间一侧}
}
\]

而它们通过 \(A\) 紧密联系。

事实上，如果

\[
A^TA v=\lambda v,\qquad \lambda>0,
\]

那么左乘 \(A\)：

\[
AA^T(Av)
=
A(A^TA)v
=
\lambda Av.
\]

所以 \(Av\) 就是 \(AA^T\) 对应同一个特征值 \(\lambda\) 的特征向量方向。

你现在可以先记住一句最关键的：

\[
\boxed{\text{\(A^TA\) 与 \(AA^T\) 不相等，但绝对不是没关系；它们共享相同的非零特征值。}}
\]

而 \(a^Ta\) 与 \(aa^T\) 只是这个一般结论在“\(A\) 只有一列”时的最简单版本。

## 什么叫共享相同的非零特征值？

意思是：虽然 \(A^TA\) 和 \(AA^T\) 往往大小不同，但它们所有 **大于 0 的特征值 eigenvalues** 是一样的，而且重数也一样。

例如

\[
A=
\begin{bmatrix}
1&0\\
0&2\\
0&0
\end{bmatrix}
\]

那么

\[
A^TA=
\begin{bmatrix}
1&0\\
0&4
\end{bmatrix},
\]

它的特征值是

\[
1,\ 4.
\]

而

\[
AA^T=
\begin{bmatrix}
1&0&0\\
0&4&0\\
0&0&0
\end{bmatrix},
\]

它的特征值是

\[
1,\ 4,\ 0.
\]

你看：

\[
A^TA:\quad 1,\ 4
\]

\[
AA^T:\quad 1,\ 4,\ 0
\]

共同的非零特征值就是

\[
\boxed{1,\ 4}.
\]

之所以我强调“**非零**”，是因为 \(A^TA\) 是 \(n\times n\)，而 \(AA^T\) 是 \(m\times m\)。如果 \(m\neq n\)，两边特征值总数本来就不一样，多出来的位置只能由 \(0\) 补上。

更关键的是为什么会共享。假设

\[
A^TA v=\lambda v,\qquad \lambda\neq0,
\]

两边左乘 \(A\)：

\[
A(A^TA)v=A(\lambda v),
\]

得到

\[
AA^T(Av)=\lambda(Av).
\]

这就说明：如果 \(v\) 是 \(A^TA\) 对应 \(\lambda\) 的特征向量，那么 \(Av\) 就是 \(AA^T\) 对应**同一个 \(\lambda\)** 的特征向量。

所以：

\[
\boxed{
A^TA \text{ 和 } AA^T
\text{ 的非零特征值完全相同}
}
\]

而到了 SVD，你会发现这些共同的非零特征值正好就是

\[
\boxed{\lambda_i=\sigma_i^2}
\]

也就是 **奇异值 singular value 的平方**。

你甚至可以把它理解为：\(A^TA\) 和 \(AA^T\) 是在两个不同空间里，看同一个线性变换的“强度结构”。

## `eig(rand(10,10)) ` sympy 能实现吗？

可以，但 **SymPy 不太适合直接模仿 `eig(rand(10,10))` 做大型随机浮点矩阵的数值特征分解**。如果你只是想像 MATLAB/NumPy 那样生成一个 \(10\times10\) 随机矩阵并求特征值，NumPy 更合适。

SymPy 可以这样：

```python
from sympy import Matrix
import random

A = Matrix(10, 10, lambda i, j: random.random())

eigenvalues = A.eigenvals()
print(eigenvalues)
```

其中：

```python
A.eigenvals()
```

对应“求特征值”，返回类似：

```python
{
    λ1: 1,
    λ2: 1,
    ...
}
```

如果还要特征向量：

```python
A.eigenvects()
```

它返回：

```text
[
    (特征值，代数重数，[特征向量]),
    ...
]
```

不过你这里的：

```text
eig(rand(10,10))
```

如果目的只是看看**随机矩阵的 10 个特征值长什么样**，建议直接：

```python
import numpy as np

A = np.random.rand(10, 10)

print(A)

eigenvalues, eigenvectors = np.linalg.eig(A)

print(eigenvalues)
```

这和你写的 `eig(rand(10,10))` 思路最接近。

### SymPy 和 NumPy 在这里的区别

**SymPy** 强项是我们最近学的这种：

```python
from sympy import Matrix, Rational

A = Matrix([
    [Rational(4, 5), Rational(3, 10)],
    [Rational(1, 5), Rational(7, 10)],
])

A.eigenvals()
A.eigenvects()
A.diagonalize()
```

它会尽量给你

\[
\lambda=1,\quad \frac12
\]

这样的**精确答案**。

而 NumPy 是：

\[
\lambda\approx1.000000,\quad0.500000
\]

所以可以简单记成：

> **学习线性代数、看精确结构 → SymPy**\
> **随机大矩阵、数值计算 → NumPy**

你现在 Strang 特征值这一章，其实 **SymPy 的 `eigenvals()`、`eigenvects()`、`diagonalize()` 三个基本就够用了**。
