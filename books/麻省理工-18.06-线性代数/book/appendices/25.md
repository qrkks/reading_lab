## sympy 有函数判断正定吗？

有。SymPy 里可以直接判断矩阵是否**正定（positive definite）**：

```python
from sympy import Matrix

A = Matrix([
    [2, 1],
    [1, 2],
])

A.is_positive_definite
```

结果：

```python
True
```

注意它是**属性（property）**，不是函数，所以不是：

```python
A.is_positive_definite()  # ❌
```

而是：

```python
A.is_positive_definite  # ✅
```

相关的几个判断也都有：

```python
A.is_positive_definite  # 正定
A.is_positive_semidefinite  # 半正定
A.is_negative_definite  # 负定
A.is_negative_semidefinite  # 半负定
A.is_indefinite  # 不定
```

比如：

```python
B = Matrix([[1, 0], [0, -2]])

B.is_indefinite
```

得到：

```python
True
```

### 你现在还可以顺便用特征值验证

对于你目前讨论的**实对称矩阵**：

```python
A.eigenvals()
```

例如：

```python
A = Matrix([[2, 1], [1, 2]])

A.eigenvals()
```

会得到类似：

```python
{3: 1, 1: 1}
```

两个特征值都 \(>0\)，所以：

\[
\boxed{A\succ0}
\]

这正好对应你刚学的：

\[
\boxed{
A\text{ 对称正定}
\iff
\lambda_i>0\ \forall i
}
\]

还可以检查对称性：

```python
A.is_symmetric()
```

所以你自己练习时，我很推荐：

```python
A.is_symmetric()
A.is_positive_definite
A.eigenvals()
```

三个一起看。这样不是单纯让 SymPy 告诉你答案，而是能同时把**对称性 → 特征值 → 正定性**串起来。

另外，如果矩阵含有符号参数，SymPy 有时无法确定，会返回：

```python
None
```

这不是 False，而是“根据当前假设无法判断”。

## sympy 里有函数算二次型吗？

有，不过 SymPy 里通常**不需要专门的“二次型函数”**，直接按定义算：

\[
q(x)=x^TAx
\]

例如：

```python
import sympy as sp

A = sp.Matrix([[2, 1], [1, 3]])

x1, x2 = sp.symbols("x1 x2", real=True)
x = sp.Matrix([x1, x2])

q = (x.T * A * x)[0]
sp.expand(q)
```

得到：

```python
2 * x1**2 + 2 * x1 * x2 + 3 * x2**2
```

这里 `[0]` 是因为

```python
x.T * A * x
```

得到的是一个 \(1\times1\) 矩阵：

```python
Matrix([[2 * x1**2 + 2 * x1 * x2 + 3 * x2**2]])
```

取 `[0]` 就变成普通标量表达式。

也可以写得更符合“内积”的感觉：

```python
q = x.dot(A * x)
```

一样得到

\[
\boxed{2x_1^2+2x_1x_2+3x_2^2}.
\]

如果你想算带 \(\frac12\) 的能量形式：

```python
E = sp.Rational(1, 2) * x.dot(A * x)
sp.expand(E)
```

就是：

\[
\boxed{
x_1^2+x_1x_2+\frac32x_2^2
}
\]

而且你现在正好可以把几个操作连起来练：

```python
A.is_symmetric()
A.is_positive_definite
A.eigenvals()
x.dot(A * x)
```

分别看：

\[
\boxed{
\text{对称性}
\rightarrow
\text{正定性}
\rightarrow
\text{特征值}
\rightarrow
\text{二次型}
}
\]

这套特别适合你现在这一节。

# sympy 取主子式，算主元，算特征值，算二次型

## A[:1,:1]这样不比我那样好

对，**如果你就是要取左上角那个顺序主子矩阵，`A[:1, :1]` 这种切片写法更好、更简洁。**

比如：

```python
A[:1, :1]
```

得到左上角 \(1\times1\)：

\[
[a_{11}]
\]

```python
A[:2, :2]
```

得到左上角 \(2\times2\)：

\[
\begin{bmatrix}
a_{11}&a_{12}\\
a_{21}&a_{22}
\end{bmatrix}
\]

```python
A[:3, :3]
```

得到左上角 \(3\times3\)。

所以检查 **leading principal minors（顺序主子式）** 时，最自然就是：

```python
for k in range(1, A.rows + 1):
print(A[:k, :k].det())
```

你原来的

```python
A[[0, 1], [0, 1]]
```

更适合这种情况：

```python
A[[0, 2], [0, 2]]
```

也就是“我要取第 1、3 行和第 1、3 列”这种**不连续的主子矩阵**。

所以可以区分成：

\[
\boxed{
A[:k,:k]
\rightarrow
\text{顺序主子矩阵}
}
\]

\[
\boxed{
A[[0,2],[0,2]]
\rightarrow
\text{任意指定的主子矩阵}
}
\]

如果你当前目的只是 Sylvester criterion，那确实 `A[:k, :k]` 更漂亮。

## 主元怎么算来着？

主元（pivot）就是高斯消元过程中，每一步用来消元的那个对角元素。最直接的办法就是把矩阵消成上三角矩阵 \(U\)，然后看 \(U\) 的对角线。
比如你刚才这个：
\[ A= \begin{bmatrix} 1&-1&0\\ -1&2&-1\\ 0&-1&2 \end{bmatrix}. \]
先用第一行消掉下面的 \(-1\)：
\[ R_2\leftarrow R_2+R_1 \]
得到
\[ \begin{bmatrix} 1&-1&0\\ 0&1&-1\\ 0&-1&2 \end{bmatrix}. \]
再用第二行消掉第三行的 \(-1\)：
\[ R_3\leftarrow R_3+R_2 \]
得到
\[ U= \begin{bmatrix} 1&-1&0\\ 0&1&-1\\ 0&0&1 \end{bmatrix}. \]
所以主元就是
\[ \boxed{p_1=1,\quad p_2=1,\quad p_3=1}. \]
也就是：
\[ \boxed{\text{pivots = 消元后的 }U\text{ 的对角元}} \]
你现在正在学正定矩阵，还有一个特别方便的公式。
如果没有换行，并且令顺序主子式为
\[ \Delta_k=\det(A[:k,:k]), \]
那么：
\[ \boxed{ p_1=\Delta_1,\qquad p_2=\frac{\Delta_2}{\Delta_1},\qquad p_3=\frac{\Delta_3}{\Delta_2},\ldots } \]
也就是：
\[ \boxed{p_k=\frac{\Delta_k}{\Delta_{k-1}}} \]
其中约定 \(\Delta_0=1\)。
你这个矩阵：
\[ \Delta_1=1,\qquad \Delta_2=1,\qquad \Delta_3=1, \]
所以：
\[ p_1=1, \]\[ p_2=\frac11=1, \]\[ p_3=\frac11=1. \]
正好就是：
\[ \boxed{1,1,1}. \]
在 SymPy 里，如果想从 LU 分解看主元，可以：
L, U, perm = A.LUdecomposition() display(U) display(U.diagonal())
如果没有发生行交换，U.diagonal() 就是主元。
所以你现在可以把三件事连起来：
\[ \boxed{ \Delta_k \longrightarrow p_k=\frac{\Delta_k}{\Delta_{k-1}} \longrightarrow \prod p_k=\det A } \]
这就是顺序主子式、主元、行列式之间的关系。

## 特征值怎么算来？

SymPy 里算特征值直接用：
A.eigenvals()
比如你这个矩阵：
from sympy import Matrix from IPython.display import display A = Matrix([ [1, -1, 0], [-1, 2, -1], [0, -1, 2], ]) display(A.eigenvals())
会返回一个字典，形式类似：
{ 特征值 1: 重数，特征值 2: 重数，... }
如果你只想拿到特征值列表，可以：
list(A.eigenvals().keys())
如果还想看对应的特征向量，用：
A.eigenvects()
它会给出：
[ (特征值，代数重数，[特征向量...]), ... ]
你现在这章最常用的几个 SymPy 方法可以放一起：
A.is_positive_definite A.eigenvals() A.eigenvects() A.det() A.trace()
分别对应：
\[ \text{正定性、特征值、特征向量、行列式、迹} \]
而且你还能用特征值验证正定：
\[ \boxed{A\text{ 对称正定}\iff \text{所有特征值}>0} \]

## 二次型怎么算？

在 SymPy 里算二次型，最直接就是按定义：

\[
q(x)=x^TAx
\]

比如：

```python
import sympy as sp
from sympy import Matrix
from IPython.display import display

A = Matrix([
    [1, -1, 0],
    [-1, 2, -1],
    [0, -1, 2],
])

x1, x2, x3 = sp.symbols("x1 x2 x3", real=True)

x = Matrix([x1, x2, x3])

q = x.dot(A * x)

display(sp.expand(q))
```

结果就是：

\[
\boxed{
x_1^2-2x_1x_2+2x_2^2-2x_2x_3+2x_3^2
}
\]

你也可以写成：

```python
q = (x.T * A * x)[0]
```

和 `x.dot(A*x)` 是一样的。

所以你现在可以直接记：

```python
q = x.dot(A * x)
```

就是：

\[
\boxed{x^TAx}
\]

如果要算某个具体向量，比如

\[
x=
\begin{bmatrix}
1\\2\\3
\end{bmatrix},
\]

就写：

```python
x = Matrix([1, 2, 3])
q = x.dot(A * x)
display(q)
```

这时得到的就是一个具体标量。
